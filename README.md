# AI-Assisted DDoS Anomaly Detection on AWS

## Overview

Designed a proof-of-concept AWS architecture that combines **cloud security controls and machine-learning anomaly detection** to identify suspicious web traffic and support controlled DDoS mitigation.

The project demonstrates how AI can complement traditional cybersecurity defenses while maintaining availability, performance, and security.

## Technologies

**AWS:** EC2 • CloudFront • WAF • Shield • Kinesis • SageMaker • Lambda • CloudWatch • SNS • S3 • IAM

**AI/ML:** Random Cut Forest • Anomaly Detection • Unsupervised Learning

**Security:** DDoS Mitigation • Defense in Depth • IAM • Encryption • Monitoring • Automated Response

## Architecture

Traffic flows through AWS security controls before reaching an EC2-hosted application. Telemetry is streamed through Kinesis and analyzed using **Amazon SageMaker Random Cut Forest**, with Lambda supporting controlled mitigation actions when anomalous activity is detected.
